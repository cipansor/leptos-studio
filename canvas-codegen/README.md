# canvas-codegen

Turn a canvas component tree into source code for eleven targets: Leptos, React,
Vue, Svelte, TypeScript, HTML, Tailwind HTML, CSS, Markdown, JSON and JSON Schema.

A `CanvasComponent` tree describes a UI the way a visual builder holds it: a list
of components, each with a style, an optional animation and nested children. This
crate walks that tree and emits source. It needs no browser and no wasm, so it
runs in a CLI, a build script or a server as readily as in a wasm front end.

## Usage

```rust
use canvas_codegen::domain::{ButtonComponent, CanvasComponent};
use canvas_codegen::generators::{LeptosGenerator, ReactGenerator};
use canvas_codegen::CodeGenerator;

let components = vec![CanvasComponent::Button(ButtonComponent::new("Click me".into()))];

let leptos = LeptosGenerator::new(Default::default()).generate(&components, &[])?;
let react = ReactGenerator.generate(&components, &[])?;
# Ok::<(), canvas_codegen::domain::AppError>(())
```

A caller that wants to choose a target at runtime can hold a `Box<dyn
CodeGenerator>`, since every target implements the same trait.

## Attribution

No generator writes a product name into its output by default. To add one, pass a
`GeneratorConfig`:

```rust
use canvas_codegen::{GeneratorConfig, CodeGenerator};
use canvas_codegen::generators::CssGenerator;
use canvas_codegen::domain::{ButtonComponent, CanvasComponent};

let components = vec![CanvasComponent::Button(ButtonComponent::new("Click me".into()))];
let config = GeneratorConfig::with_attribution("Generated by My Builder");
let css = CssGenerator.generate_with(&config, &components, &[])?;
# Ok::<(), canvas_codegen::domain::AppError>(())
```

## Targets

| Target | Type | Extension |
| --- | --- | --- |
| Leptos | `LeptosGenerator` | `rs` |
| React | `ReactGenerator` | `tsx` |
| Vue | `VueGenerator` | `vue` |
| Svelte | `SvelteGenerator` | `svelte` |
| TypeScript | `TypeScriptGenerator` | `d.ts` |
| HTML | `HtmlGenerator` | `html` |
| Tailwind HTML | `TailwindHtmlGenerator` | `html` |
| CSS | `CssGenerator` | `css` |
| Markdown | `MarkdownGenerator` | `md` |
| JSON | `JsonGenerator` | `json` |
| JSON Schema | `JsonSchemaGenerator` | `schema.json` |

## Minimum supported Rust version

Rust 1.89.0.
