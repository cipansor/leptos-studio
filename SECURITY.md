# Security Policy

## Supported versions

Security fixes are applied to the latest release line only.

## Reporting a vulnerability

Do not disclose security issues publicly.

Report vulnerabilities through GitHub private vulnerability reporting, and
track the resulting advisory on the repository's Security Advisories page:

- Report: https://github.com/cipansor/leptos-studio/security/advisories/new
- Advisories: https://github.com/cipansor/leptos-studio/security/advisories

Please do not use public issues, pull requests or any other channel.

Include as much detail as possible:

- affected version
- steps to reproduce
- impact assessment
- any proof of concept or logs

## Response process

The maintainers will review reports, confirm impact, and coordinate a fix before
public disclosure.
